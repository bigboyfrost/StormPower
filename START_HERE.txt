What you need
  • Windows PC
  • Stormworks: Build and Rescue

Install (friends)
  1. Download StormPower-Setup-*.exe from:
       https://github.com/bigboyfrost/StormPower/releases/latest
  2. Run the installer (desktop shortcut is created automatically)
  3. Launch StormPower from the desktop shortcut
  4. In Stormworks: enable the "StormPower" addon on your save
  5. Reload the world (or type ?reload_scripts in chat)
  6. Click the floating SP button

Updates
  • StormPower checks GitHub for updates automatically
  • When an update is found you get an overlay banner AND an in-game
    Stormworks notify/announce (while the addon is connected)
  • Use Other → Check for Updates, or the in-app Update screen
  • No Node.js and no zip folders required
  • Mega Wave Engine: toggle from Weather & Waves / Other in the menu
    (restart Stormworks after installing or removing the patch)

If Windows SmartScreen warns
  • Click More info → Run anyway (unsigned build until a cert is added)

Dev / source folder (optional)
  • Node.js LTS → https://nodejs.org/
  • install.bat then start.bat

Tips
  • Use Borderless Window in Stormworks so the overlay shows
  • Exclusive fullscreen hides external windows — use chat (?sp)
  • Spawn distance slider controls how far things / tsunamis appear
  • Flip Boost Direction is under Other if vehicle boost goes backward

Icon
  • Temporary stock icon ships in build/icon.ico
  • Drop your final art as build/icon.png and rebuild the installer
